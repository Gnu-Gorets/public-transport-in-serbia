# Увеличение карты при выборе автобуса

## План

- Сверить текущее поведение карты и целевую ветку `main`; не затрагивать имеющиеся изменения пользователя в странице остановки.
- При открытии остановки показывать остановку и все актуальные автобусы с масштабом на 8% свободнее минимального fit.
- Добавить минимальную проверку поведения по существующему шаблону тестов.
- Выполнить lint, format check и тесты; проверить итоговый diff и создать коммит только с изменениями этой задачи.
- Проверить читаемость номера автобуса в изолированном Chromium profile на странице станции.
- Увеличить номер непосредственно внутри SVG-маркера автобуса и сохранить его текущий силуэт и цвета.
- Выполнить проектные проверки, проверить итоговый diff и создать коммит только с изменениями этой задачи.

## Находки по читаемости номера

- Текущий номер внутри SVG занимает 8px при ширине таблички 24px; изменение до 10px недостаточно по новому скриншоту.
- Tooltip `my-labels` относится к старой карте и не влияет на SVG-маркеры текущей страницы станции; незакоммиченное изменение `static/index.css` изолировать и не включать в коммит.
- Первый запуск Chromium попал на временное состояние `socket hang up`; повторный запуск из того же изолированного profile загрузил страницу станции и новые маркеры.


## Находки

- В `src/lib/components/map/StationMap.svelte` остановка и координаты автобусов объединяются в bounds, затем вызывается `fitBounds` с padding `[48, 48]`, `maxZoom: 13`.
- Bus markers не имели click handler; поэтому выбор автобуса на карте не запускал фокусировку.
- В рабочем дереве есть незапрошенные изменения `src/routes/stations/[city]/[id]/+page.svelte`; сохранить их нетронутыми и не включать в коммит.
- `StationMap.svelte` отсутствует в `main`, поэтому сравнить именно эту реализацию с `main` нельзя; текущая feature-ветка содержит новый Svelte UI.

## Выполнено

- При открытии остановки и клике по bus marker фокусироваться на bounds остановки и всех автобусах с масштабом на 8% свободнее минимального fit; `maxZoom: 13` сохранён.
- Включён дробный `zoomSnap`, чтобы Leaflet не округлял 6% до целого уровня.
- Первичное ограничение `maxZoom: 13` обрезало рассчитанный прирост на близких автобусах. Ограничение заменено на реальный `map.getMaxZoom()`.
